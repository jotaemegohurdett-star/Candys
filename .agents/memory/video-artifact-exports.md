---
name: Video artifacts and exports
description: Distinction between live video artifacts and downloadable MP4 exports.
---

The live Animation artifact and rendered MP4 files are separate deliverables. A download link must point to a dedicated rendered file whose format and content match the labeled deliverable; never relabel a different export or an unrelated sample clip as Animation.

**Why:** The project exposed an interactive Animation artifact alongside Instagram and web MP4s, and treating the artifact as if it were already a distinct MP4 caused mismatched download links.

**How to apply:** Before adding or changing video download controls, map each visible deliverable to its actual file path, dimensions, audio track, and render source. Keep website embeds separate from download delivery controls unless explicitly requested.
